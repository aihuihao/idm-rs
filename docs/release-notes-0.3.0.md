# idm-rs 0.3.0 版本说明

本次主要特性：程序自动更新（Tauri updater）与下载启动竞态修复。程序版本号由 0.2.0 升至 0.3.0；Firefox 扩展未改动，版本仍为 0.1.0。

## 本次新增与修复

- **暂停竞态修复**：运行器在启动任务前用条件更新把数据库状态从 `Queued` 原子地改为 `Probing`；若任务已被 CLI/桌面暂停（更新 0 行），则放弃启动。原有「运行器已 spawn、尚未连上服务器时暂停失效」的问题已修复，新增回归测试覆盖。
- **Probing 状态完整呈现**：界面把 `Probing` 显示为「连接中」，并纳入暂停按钮、下载中/未完成分类与计数；失败兜底与续传入口同步处理该状态。
- **程序自动更新**：配置 Tauri v2 updater（公钥、GitHub `latest.json` 端点、Windows passive 安装）。默认每 24 小时检查一次（启动 30 秒后首次），可在选项中关闭；支持手动检查、显示更新说明与下载进度。
- **安全停止与恢复**：安装前安全停止运行器（活动任务变为 `Paused(User)` 并释放运行器锁），下载或签名校验失败时自动恢复运行器；后台运行器占用时禁止安装并给出中文提示。
- **签名发布流程**：`build-release.ps1 -Sign` 使用用户提供的私钥与交互式密码生成签名更新产物，并调用 `scripts/make-latest-json.ps1` 生成 `dist/latest.json`；默认不签名构建关闭 updater 产物生成。

## 已知限制

- **仅支持 Windows 与 Firefox**：桌面程序仅提供 Windows 安装包；浏览器接管扩展仅支持 Firefox（Manifest V2）。
- **程序未做代码签名**：安装时 Windows 可能显示"未知发布者"提示，需用户手动确认继续。
- **自动更新需要用户完成签名发布**：仓库中的构建均为不签名模式；只有用户按 `docs/maintenance.md` 完成签名构建并把安装包与 `latest.json` 上传到 GitHub Release 后，已安装用户才会收到更新。
- **观察模式下不能安装更新**：另一个运行器正在运行时只能检查更新，需先停止该运行器再更新。
- **Tauri 升级时需同步自定义安装模板**：详见 `docs/maintenance.md`。
