## 第 0 步：修复暂停竞态
v0.2.0 报告提到：运行器已启动某任务、但在连上服务器之前，数据库状态仍为 Queued，此时 CLI 的 queue pause 会成功写入 Paused，随后下载程序又把状态改为 Downloading，暂停失效。
1. 先写测试复现：用慢速响应的本地服务器（连接后延迟响应），运行器启动任务后立即用 CLI 暂停，断言要么 CLI 返回"正在下载"（退出码 3），要么任务最终保持 Paused 且不下载；在当前代码上应失败
2. 修复方向：运行器在开始下载一个任务时，先把数据库状态改为 Probing（不能从 Paused 改，只能从 Queued 改，用带条件的更新，更新 0 行说明已被暂停，此时放弃启动该任务）；CLI 的 queue pause 已把 Probing 视为正在下载
3. 原有全部测试必须通过

## 第 2 步：构建脚本
1. build-release.ps1 默认不签名：通过 Tauri CLI 的配置覆盖参数关闭 createUpdaterArtifacts，使没有私钥时也能正常构建。你的全部验证都使用这个模式
