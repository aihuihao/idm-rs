# 任务：idm-rs Phase 1d —— 分块级自动重试

沿用全部工作规则。先把本任务原文保存为 `docs/prompts/phase1d.md`，`git status` 必须干净。
本阶段只做分块级重试。连接数自动调节、全局限速等留到 Phase 3。真实网络下载必须带 `--max-speed`。

## 一、错误分类

在 `crates/idm-core/src/net/` 新增 `retry.rs`，实现 `fn is_retryable(&Error) -> bool`，并为每一类写单元测试：

**可重试（临时性错误）**
- 连接失败、连接被重置、读取空闲超时（reqwest 的 `is_connect()`、`is_timeout()`、`is_request()`、`is_body()` 等，按实际 API 判断）
- `UnexpectedEof`（中途断开）
- HTTP 408、429、500、502、503、504

**不可重试（直接失败）**
- `RemoteChanged`、`RangeNotHonored`、`InvalidContentRange`、`UnsupportedContentEncoding`
- 上面没有列出的其他 HTTP 4xx（例如 403、404、416）
- 磁盘满（按原规则暂停任务）、取消、任何磁盘写入错误

## 二、重试机制

1. **重试位置**：分块出错后，从该分块当前的写入位置（即 acked 位置，等于 ChunkWriter 的当前位置）重新发送 Range 请求，直到区间终点。ChunkWriter 保持注册状态，不注销也不重新申请。不得从分块起点重新下载
2. **退避等待**：指数退避加随机抖动。第一次等 1 秒，之后每次翻倍，最长 30 秒；抖动幅度为 ±20%。不引入 rand，随机数用简单的 xorshift，以时间作为种子即可
3. **Retry-After**：响应码为 429 或 503 且带有 `Retry-After` 头时（秒数格式），按该值等待，但最长不超过 60 秒
4. **次数上限**：
   - 连续失败次数上限默认 5 次（`DownloadConfig.max_retries`）。某次尝试只要写入了至少 1 MiB 的数据，就把连续失败计数清零
   - 另设每个分块的总尝试次数硬上限：100 次。防止服务器每次都在发送少量数据后断开，导致无限循环
   - 超过任一上限后，分块失败，任务按原规则变为 Failed（可以 resume）。错误信息中要包含尝试次数和最后一次的错误
5. **取消**：退避等待期间也要监听取消信号，收到后 1 秒内退出
6. **限速**：重试后继续使用同一个限速器
7. **请求选项**：每次重试的请求都要带上与首次请求相同的 If-Range 和 ETag 校验规则
8. **日志与统计**：每次重试输出一条 warn 日志，字段包括 task_id、chunk_id、第几次尝试、错误内容、等待时长、本次续传的起始位置。进度快照和 CLI 的分块汇总表中，新增每个分块的重试次数一列
9. **CLI**：`download` 和 `resume` 新增 `--max-retries <N>` 参数，默认 5，设为 0 表示不重试

## 三、测试（用本地测试服务器）

1. 前 N 个响应在中途断开 → 重试后成功，最终文件逐字节正确，汇总表中的重试次数等于 N
2. **从断点继续**：检查测试服务器收到的 Range 请求头，确认重试请求的起始位置正好等于断开前已写入的位置，而不是分块起点
3. 发送一部分数据后停顿，停顿时间超过 read_timeout，只发生一次 → 重试后成功
4. 返回 503 并带 `Retry-After: 2` → 等待约 2 秒（允许 ±0.5 秒）后重试成功
5. 持续返回 500 → 第 6 次尝试失败后分块失败（即重试了 5 次），任务变为 Failed，.idm-part 保留；之后修复服务器再执行 resume，能完整下载
6. 服务器每次发送 2 MiB 后断开 → 因为每次都有进展，连续失败计数不断清零，最终能下载完成；再构造一个"每次只发 1 KiB 就断开"的场景，验证总尝试次数达到 100 次后失败
7. 不可重试的错误（RemoteChanged、RangeNotHonored、404、gzip）→ 只尝试 1 次就失败，重试次数为 0
8. 在退避等待期间取消 → 1 秒内返回 Cancelled
9. 限速和重试同时生效时，总速度仍不超过限速值的 120%
10. `--max-retries 0` 时，首次出错就失败
11. （1c.1 遗留）通过测试钩子让最后一次检查点返回磁盘满错误 → 任务变为 Paused(DiskFull)，不改名
12. 原有测试和崩溃测试全部通过
